Back up your settings

Publish a copy as cues.json in the same folder as this page. Any phone that opens the app fresh will pick it up.

Putting it on GitHub
  1. Tap Save above, then Copy settings.
  2. In your repository, tap Add file → Create new file.
  3. Name it exactly cues.json and paste into the box below the name.
  4. Commit it. Give it a minute, then open the app on the other phone.

To change it later, open cues.json on GitHub, tap the pencil, and paste a fresh copy over the old one.

How to set it up

Getting the Spotify links
  1. In Spotify, tap the ••• on a song or playlist → Share → Copy link.
  2. Paste it into the Link box above. It gets converted so it opens the Spotify app rather than the website.
  3. For the exit playlist, copy the link to the first song, not the playlist, then turn on shuffle-off and let it run on.
The volume shortcut (one-time, 2 minutes)
  1. Open Shortcuts → + → name it Wedding Cue.
  2. Add Split Text. Set its input to Shortcut Input, and set Separator to Custom → |
  3. Add Set Volume. Tap the percentage, then insert the variable Split Text → Get Item at Index → 1.
  4. Add Open URLs. Insert the variable Split Text → Get Item at Index → 2.
  5. In the shortcut's settings, allow it to run from other apps.

If your iOS won't let you put a variable in Set Volume, use the fallback instead: make a separate small shortcut per cue (Set Volume → Open URLs), and in the cue's Mode above choose "Run a named shortcut".

The song that isn't on Spotify
  1. Put the audio file in the Files app, under On My iPhone so it needs no signal.
  2. New shortcut, named e.g. Hymn Two. Add Calculate: Shortcut Input ÷ 100.
  3. Add Set Volume and insert the Calculate result.
  4. Add File and browse to the song, then Play Sound with the File variable.
  5. Set this cue's Mode to "Run a named shortcut" and put the shortcut's name in the Link box. The volume above is sent to it.

Once it starts, stopping it early is awkward, so let this one play to the end.

Putting it on the Home Screen
  1. Finish your settings above and tap Save.
  2. In Safari, tap the share button → Add to Home Screen.
  3. Open it once from the new icon while you still have wifi. That stores the whole app on the phone.
  4. From then on you can edit the settings from the icon itself and they will stick.
  5. Turn on Airplane Mode and open it again. If it still works, it will work at the venue.

If you change the settings later, save and then add it to the Home Screen again — the icon remembers the settings from the moment it was added.

Before the ceremony
  1. Settings → Display → Auto-Lock → Never.
  2. Turn on Do Not Disturb and lock the screen rotation.
  3. Download every Spotify track for offline play, in case the venue has no signal.
  4. Pair the Bluetooth speaker and play something quietly during the waiting playlist so it can't fall asleep before the exit.
  5. Run through all cues once with Rehearse on, with the actual speaker in the actual room.
